# Gateway & Real-Time Events

Discord Gateway is a persistent WebSocket connection through which bots receive real-time dispatch events and maintain presence.

* [Connecting & Lifecycle](connecting/): Connecting, session resumption, heartbeat keepalives, and graceful shutdown.
* [Gateway Intents](intents/): Standard and privileged intents, message content, and filtering event traffic.
* [Listening to Events](events/): Registering event callbacks, typed event payloads, and concurrent execution modes.
* [Bot Presence & Status](presence/): Setting online, idle, or do not disturb status and custom rich activities.
