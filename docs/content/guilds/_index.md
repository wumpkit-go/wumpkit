# Guilds & Moderation

Discord servers (guilds) contain channels, members, roles, and administrative audit logs.

wumpkit provides complete coverage of Discord's guild REST endpoints, giving you full control over server configuration and moderation automation.

* [Channels](channels/): Creating channels, channel types, editing properties, position sorting, and permission overwrites.
* [Members](members/): Fetching members, searching member lists, changing nicknames, and voice state management.
* [Moderation & Bans](moderation/): Kicking users, banning, unbanning, bulk bans, timeouts, and audit reasons.
* [Roles & Permissions](roles/): Creating server roles, assigning roles to members, role hierarchies, and permission bitfields.
* [Audit Logs](audit-logs/): Inspecting server administrative history, filters, action types, and change diffs.
