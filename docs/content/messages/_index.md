# Messages & Content

Discord messages support rich content including embeds, file attachments, interactive components, polls, and reactions.

* [Sending & Editing Messages](sending-messages/): Plain text messages, replies, mention controls, editing, and deleting.
* [Rich Embeds](embeds/): Creating rich embeds, author, footer, thumbnails, and color styling.
* [File Uploads](attachments/): Uploading files from disk or memory, image attachments, and alt text.
* [Native Polls](polls/): Creating server polls, multiple choice answers, duration, and expiring polls.
* [Emoji Reactions](reactions/): Adding, deleting, and inspecting user reactions.
* [Paginating Message History](history/): Traversing channel history with automated cursor pagination.
