# Webhooks & HTTP Bots

wumpkit supports both traditional Discord webhooks and modern HTTP-only serverless bot interactions.

* [Incoming Webhooks](incoming-webhooks/): Creating webhooks, sending messages with custom names and avatars, and thread routing.
* [Serverless & HTTP Events](http-interactions/): Handling Discord slash commands and events over HTTP without a continuous WebSocket gateway connection.
