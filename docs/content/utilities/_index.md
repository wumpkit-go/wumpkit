# Utilities & Formatting

wumpkit provides type-safe helpers for text formatting, Discord palettes, and snowflake ID calculations:

* [Markdown & Mentions](markdown/): Text styling helpers, dynamic timestamps, and user/channel/role mention tags.
* [Colors & Palettes](colors/): Embed color presets, hex color parsing, and RGB conversion.
* [Snowflakes & IDs](snowflakes/): Parsing snowflake IDs, extracting creation timestamps, shard routing formulas, and decoding bot tokens.
